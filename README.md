# mebius-photos

Фото и XML-фид для автозагрузки объявлений школы математики «Мёбиус» на Авито.

- `mebius-01.png` … `mebius-09.png` — фото объявлений, 1600×1200
- `feed.xml` — фид автозагрузки, 100 карточек

Ссылка для Авито (Автозагрузка → Настройки → загрузка по ссылке):

```
https://raw.githubusercontent.com/aksenevich2003-prog/mebius-photos/main/feed.xml
```
